# auto-browsing-shuiyuan-bbs

使用本机 Microsoft Edge 登录会话采集上海交通大学水源社区主题与完整可访问回复，生成 Markdown 日报及 JSON 完整资料。

## 快速使用

1. 首次使用或登录过期时，双击 `首次登录水源.bat`，在专用 Edge 窗口完成统一身份认证。
2. 双击 `运行水源日报.bat`，生成过去 24 小时内首发主题的日报。
3. 双击 `运行水源增量日报.bat`，生成上次成功运行后有新回复或编辑的主题日报。

报告保存在本地 `水源日报输出` 目录。登录会话、Cookie、采集正文和生成报告均已通过 `.gitignore` 排除，不会提交到仓库。

详细说明见 [水源日报脚本说明.md](./水源日报脚本说明.md)。
